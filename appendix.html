📚 이 부록에서 배우는 것

  • 13개 주요 Git 명령어의 자주 사용하는 옵션
  • 각 옵션의 의미와 실제 사용 예제
  • 옵션 조합 활용법

1️⃣ 저장소 생성: git init / clone

git init

로컬에서 새로운 Git 저장소를 만듭니다.

git init
현재 디렉터리에서 .git 폴더 생성
$ git init
git init [directory-name]
지정한 디렉터리에 새 저장소 생성
$ git init my-project

git clone

원격 저장소를 로컬에 복제합니다.

git clone [URL]
저장소를 로컬에 복제
$ git clone https://github.com/user/repo.git
git clone [URL] [directory-name]
지정한 이름의 폴더에 복제
$ git clone https://github.com/user/repo.git my-folder
git clone --depth [number] [URL]
얕은 복제 (최근 N개 커밋만)
$ git clone --depth 1 https://github.com/user/repo.git

2️⃣ 스테이징: git add

변경사항을 스테이징 영역에 추가합니다.

git add [file]
특정 파일을 스테이징
$ git add README.md
git add .
현재 디렉터리의 모든 변경사항 스테이징
$ git add .
git add -A / --all
전체 저장소의 모든 변경사항 스테이징
$ git add -A
git add -p / --patch
대화형으로 변경사항 선택해서 스테이징
$ git add -p
git add -u / --update
추적 중인 파일의 변경사항만 스테이징
$ git add -u

3️⃣ 커밋: git commit

스테이징된 변경사항을 저장합니다.

git commit -m [message]
커밋 메시지와 함께 커밋
$ git commit -m "초기 프로젝트 설정"
git commit -am [message]
추적 중인 파일 변경사항을 자동으로 스테이징 후 커밋
$ git commit -am "버그 수정"
git commit -v / --verbose
변경사항을 자세히 보며 커밋
$ git commit -v
git commit --amend
직전 커밋 수정 (메시지 변경, 파일 추가 등)
$ git commit --amend
git commit --amend --no-edit
직전 커밋에 파일 추가 (메시지 유지)
$ git commit --amend --no-edit

4️⃣ 상태 확인: git status / diff

변경사항을 확인하고 비교합니다.

git status

git status
작업 디렉터리와 스테이징 상태 확인
$ git status
git status -s / --short
축약된 형식으로 상태 표시
$ git status -s

git diff

git diff
작업 디렉터리의 변경사항 확인 (스테이징되지 않은 것)
$ git diff
git diff --staged
스테이징된 변경사항 확인
$ git diff --staged
git diff HEAD
모든 변경사항 확인 (스테이징 여부 상관없이)
$ git diff HEAD
git diff [branch1] [branch2]
두 브랜치 간의 차이 비교
$ git diff main feature

5️⃣ 히스토리 조회: git log

커밋 히스토리를 확인합니다.

git log
전체 커밋 히스토리 조회
$ git log
git log --oneline
각 커밋을 한 줄로 요약 표시
$ git log --oneline
git log -n [number]
최근 N개 커밋만 조회
$ git log -5
git log --graph --all --oneline
모든 브랜치를 그래프 형식으로 보기
$ git log --graph --all --oneline
git log --author=[name]
특정 작가의 커밋만 조회
$ git log --author="John Doe"
git log --since=[date] --until=[date]
특정 기간의 커밋 조회
$ git log --since="2024-01-01" --until="2024-12-31"
git log [file]
특정 파일의 변경 히스토리만 조회
$ git log README.md

6️⃣ 브랜치 관리: git branch / checkout / switch

브랜치를 생성, 전환, 삭제합니다.

git branch

git branch
로컬 브랜치 목록 조회
$ git branch
git branch -a / --all
로컬 + 원격 브랜치 모두 조회
$ git branch -a
git branch [branch-name]
새로운 브랜치 생성
$ git branch feature/login
git branch -d [branch-name]
브랜치 삭제 (안전 - 병합되지 않으면 경고)
$ git branch -d feature/login
git branch -D [branch-name]
브랜치 강제 삭제
$ git branch -D feature/login

git checkout

git checkout [branch-name]
브랜치로 전환
$ git checkout feature/login
git checkout -b [branch-name]
새로운 브랜치 생성 및 전환
$ git checkout -b feature/logout

git switch

git switch [branch-name]
브랜치로 전환 (최신 방식)
$ git switch feature/login
git switch -c [branch-name]
새로운 브랜치 생성 및 전환 (최신 방식)
$ git switch -c feature/logout

7️⃣ 병합: git merge / rebase

브랜치를 병합하거나 재배치합니다.

git merge

git merge [branch-name]
지정한 브랜치를 현재 브랜치에 병합
$ git merge feature/login
git merge --no-ff [branch-name]
Fast-forward 병합을 피하고 병합 커밋 생성
$ git merge --no-ff feature/login
git merge --squash [branch-name]
여러 커밋을 하나로 압축하여 병합
$ git merge --squash feature/login

git rebase

git rebase [branch-name]
현재 브랜치를 다른 브랜치 위에 재배치
$ git rebase main
git rebase -i HEAD~[number]
대화형 리베이스 (최근 N개 커밋 편집)
$ git rebase -i HEAD~3
git rebase --abort
리베이스 취소
$ git rebase --abort

8️⃣ 원격 동기화: git push / pull / fetch

원격 저장소와 동기화합니다.

git push

git push
현재 브랜치를 기본 원격(origin)에 푸시
$ git push
git push [remote] [branch]
지정한 원격과 브랜치에 푸시
$ git push origin feature/login
git push -u [remote] [branch]
푸시하면서 추적 설정 (다음부터 git push만 가능)
$ git push -u origin feature/login
git push --force / -f
강제 푸시 (⚠️ 주의: 다른 사람의 커밋 덮어씀)
$ git push -f
git push origin --delete [branch]
원격 브랜치 삭제
$ git push origin --delete feature/login

git pull

git pull
원격 저장소에서 변경사항을 가져와 병합
$ git pull
git pull --rebase
가져온 후 리베이스로 병합
$ git pull --rebase

git fetch

git fetch
원격 저장소에서 변경사항을 가져오기만 함 (병합 안함)
$ git fetch
git fetch [remote]
지정한 원격에서 가져오기
$ git fetch origin

9️⃣ 원격 저장소 관리: git remote

원격 저장소를 설정하고 관리합니다.

git remote
원격 저장소 목록 조회
$ git remote
git remote -v / --verbose
원격 저장소 목록 + URL 확인
$ git remote -v
git remote add [name] [URL]
새로운 원격 저장소 추가
$ git remote add upstream https://github.com/user/repo.git
git remote remove [name]
원격 저장소 제거
$ git remote remove upstream
git remote set-url [name] [new-URL]
원격 저장소 URL 변경
$ git remote set-url origin https://github.com/newuser/repo.git
git remote show [name]
원격 저장소의 상세 정보
$ git remote show origin

🔟 임시 저장: git stash

작업 중인 변경사항을 임시로 저장합니다.

git stash
현재 변경사항을 임시 저장
$ git stash
git stash save [message]
메시지와 함께 변경사항 저장
$ git stash save "WIP: 로그인 기능"
git stash list
임시 저장된 변경사항 목록
$ git stash list
git stash pop
가장 최근 stash 복원 및 삭제
$ git stash pop
git stash apply [stash-name]
지정한 stash 복원 (유지)
$ git stash apply stash@{0}
git stash drop [stash-name]
지정한 stash 삭제
$ git stash drop stash@{0}
git stash clear
모든 stash 삭제
$ git stash clear

1️⃣1️⃣ 되돌리기: git reset / revert / restore

변경사항을 되돌립니다.

git reset

git reset HEAD [file]
파일을 스테이징에서 제거
$ git reset HEAD README.md
git reset --soft HEAD~1
커밋만 되돌리기 (변경사항 유지)
$ git reset --soft HEAD~1
git reset --mixed HEAD~1
커밋 + 스테이징 되돌리기 (기본값)
$ git reset --mixed HEAD~1
git reset --hard HEAD~1
커밋 + 스테이징 + 파일까지 완전히 되돌리기
$ git reset --hard HEAD~1

git revert

git revert [commit]
지정한 커밋의 변경사항을 되돌리는 새 커밋 생성
$ git revert abc1234

git restore

git restore [file]
파일을 이전 상태로 복원
$ git restore README.md
git restore --staged [file]
스테이징된 파일 제거
$ git restore --staged README.md

1️⃣2️⃣ 태그: git tag

특정 커밋에 이름을 붙입니다.

git tag
태그 목록 조회
$ git tag
git tag [tag-name]
경량 태그 생성 (현재 커밋에)
$ git tag v1.0.0
git tag -a [tag-name] -m [message]
주석있는 태그 생성
$ git tag -a v1.0.0 -m "Version 1.0.0"
git tag -d [tag-name]
로컬 태그 삭제
$ git tag -d v1.0.0
git push origin [tag-name]
특정 태그 푸시
$ git push origin v1.0.0
git push origin --tags
모든 태그 푸시
$ git push origin --tags

1️⃣3️⃣ 공통 옵션

대부분의 Git 명령어에서 사용 가능한 옵션들입니다.

-v / --verbose
더 자세한 정보 출력
$ git remote -v
$ git commit -v
-h / --help
명령어 도움말 표시
$ git commit --help
-q / --quiet
조용하게 실행 (에러 메시지만 표시)
$ git push -q
--dry-run
실제 실행하지 않고 결과 미리보기
$ git push --dry-run
--no-verify
커밋/푸시 훅 스킵 (⚠️ 주의: 필요한 경우만)
$ git push --no-verify
💡 팁: 어떤 명령어든 --help 옵션을 붙이면 상세한 도움말을 볼 수 있습니다. 예를 들어 git log --help는 git log의 모든 옵션을 설명해줍니다.
