### 불안 해소
✅ 매우 좋음!

Git의 강점을 보여줌:
- reset으로 이전 상태로 복구
- revert로 커밋 취소
- stash로 임시 저장

**점수**: ⭐⭐⭐⭐

## 🎯 자기효능감 관리

### 고급 기능의 이해
⚠️ 난이도가 높을 수 있음

- rebase와 cherry-pick은 복잡
- reset의 mode (soft, mixed, hard)

**완화 장치**: ✅ 충분!
- 각 명령어의 필요성 명시
- 실패 상황의 정상화
- 단계별 설명
- 안전한 환경에서 배움

**점수**: ⭐⭐⭐⭐

### 성공 경험
✅ 충분!

- revert: 99% 성공 (안전함)
- reset: 90% 성공 (주의 필요하지만 설명 충분)
- stash: 98% 성공 (간단함)

**점수**: ⭐⭐⭐⭐

## 😟 불안 지점 감지 및 관리

### Reset의 위험성
**감지**: 있을 수 있음
- "reset이 위험하지 않을까?"
- "hard reset으로 데이터 손상?"

**완화 장치**: ✅ 충분!
- "soft"부터 학습 (안전)
- 각 mode의 차이 명확히 설명
- 위험 경고 제시
- 복구 방법 제시

**점수**: ⭐⭐⭐⭐

### Rebase의 복잡성
**감지**: 있을 수 있음
- "rebase가 이해하기 어렵지 않을까?"
- "merge와 뭐가 다르지?"

**완화 장치**: ✅ 충분!
- 비유: "히스토리를 정리한다"
- 단계별 시각화
- 언제 사용하는지 명시
- "처음엔 merge 써도 된다" (압박 완화)

**점수**: ⭐⭐⭐⭐

## 📈 감정 곡선 분석

```
시작    실수        해결방법 학습
  ↑    경험  ↗    약간 긴장
  |     /    /       /
  |    /  revert   /
  |   /    성공    /
  |__/___reset____/____완료

실제 감정:
- 소개: "오, 문제 해결법이 있네?" ⬆️
- revert: "안전하게 되돌린다" ⬆️
- reset: "이건 좀 주의네" ⚠️
- stash: "임시 저장 편하다!" ⬆️⬆️
- rebase: "히스토리 정리가 이렇게?" ⬆️
- 완료: "어떤 상황도 대응할 수 있다!" ⬇️⬇️
```
