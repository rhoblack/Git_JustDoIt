## 남은 문제점 (Minor)

1. **3장 PR 생성**: GitHub 웹 UI의 스크린샷이 여전히 없음. "Compare & pull request 버튼" 설명은 있지만, 실제 화면을 본 적 없는 초보자는 찾기 어려울 수 있음. (SVG 다이어그램으로 대체 가능)

2. **4장 vi 에디터 사용**: revert 실습에서 "vi 에디터에서는 :wq" 라고 언급하지만, vi를 처음 만나는 초보자에게는 당황스러울 수 있음. `git revert --no-edit 해시값` 옵션 소개 또는 "에디터가 열리면 이렇게 하세요" 가이드가 있으면 더 좋음.

3. **4장 rebase**: Interactive rebase에서 vi 에디터로 pick을 squash로 변경하는 과정이 초보자에게 어려울 수 있음. "이것이 어려우면 건너뛰어도 됩니다" 안내가 있어서 괜찮지만, VS Code를 기본 에디터로 설정하는 팁이 있으면 더 도움됨.

4. **5장 시나리오 5**: `git reset --hard HEAD~1`을 사용하는데, 이것이 이미 push한 경우에는 위험하다는 경고가 없음. "아직 push하지 않은 커밋" 조건을 명시하면 좋겠음. -> 실제로 safety-box에 "아직 push하지 않은 커밋에 안전하게 사용" 언급이 있으므로 큰 문제 아님.

5. **전체**: `git clone` 명령어가 교재 전체에서 소개되지 않음. 실제로 다른 사람의 프로젝트를 받아올 때 가장 먼저 사용하는 명령어인데, 2장이나 3장에 간략히 소개하면 좋겠음.
