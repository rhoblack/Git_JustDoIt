## 신규 개선 사항 (이전에 없던 우수한 추가)

### 1. .term 용어 박스 (전 장 일관 적용)
3단 구조: **한글 정의 / 일상 비유 / 왜 필요한가?** - 교육설계적으로 매우 우수. 새 용어 등장 시마다 일관된 형태로 설명하여 인지 부하를 줄임.

### 2. .safety-box 안심 장치 (3~5장)
"안심하세요" 박스가 충돌 해결, reset, rebase 등 불안감이 큰 주제에 적절히 배치됨. 심리적 안전성에 기여.

### 3. .difficulty-indicator 난이도 표시 (4장)
쉬움/중간/심화 3단계 표시가 시각적으로 명확하고, 학습자가 선택적으로 학습 가능하게 설계.

### 4. .reproduce-box 상황 재현 (5장)
시나리오 기반 학습에 "직접 만들어보기" 환경이 추가되어, 능동적 학습(Active Learning) 실현.

### 5. .error-box 에러 해결 가이드 (2장)
push 실패 시 에러 메시지와 해결 방법이 구체적으로 제시됨. 초보자가 가장 자주 겪는 문제에 대한 사전 대응.

### 6. 터미널 기초 섹션 (1장 1.1)
이전에 없던 터미널 기본 명령어(pwd, ls, mkdir, cd) 섹션이 추가되어 비프로그래머도 접근 가능.

### 7. 해시값/HEAD 독립 섹션 (3장 3.1)
이전에는 해시값이 4장에서 갑자기 등장했으나, 3장 시작에서 미리 설명하여 선수 지식 문제 해결.

### 8. reflog 섹션 (4장 4.5)
"최후의 보험"으로 별도 섹션 추가. reset --hard 실수 후 복구 경험을 직접 실습하여 심리적 안전망 제공.

### 9. .gitignore 독립 섹션 (2장 2.5)
이전에는 5장 시나리오로만 다뤘으나, 2장에서 기본 사용법을 먼저 학습하게 변경. 논리적 순서 개선.

## 잔존 이슈

### Minor 이슈 (3개)

1. **3장 PR 스크린샷 부재**: GitHub 웹 UI 기반 절차가 텍스트로만 설명됨. 스크린샷이 있으면 이해도가 높아질 수 있으나, HTML 교재 특성상 스크린샷 삽입이 어려울 수 있음.

2. **자기 점검 퀴즈 없음**: 각 장 끝에 "직접 해보기" 과제나 간단한 확인 퀴즈가 없음. 워크북이 별도로 있으므로(output/workbook/) 교재 자체에는 없어도 무방할 수 있음.

3. **4장 cherry-pick 실습 부족**: 4.6절이 다른 섹션에 비해 실습이 간략. 단, "심화" 난이도 표시가 있고 사용 빈도가 낮은 명령어이므로 현재 수준이 적절할 수 있음.
