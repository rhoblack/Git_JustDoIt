## 🛠️ Google Slides에서 생성하는 단계

### 1단계: 프로젝트 생성
```
1. Google Drive (drive.google.com) 접속
2. "새로 만들기" → "Google Slides" 클릭
3. 제목: "Chapter 1: Git 시작하기"
```

### 2단계: 마스터 슬라이드 설정
```
1. 메뉴: 슬라이드 → 슬라이드 마스터
2. 주색 배경 추가
   - 배경색: #667eea
   - 텍스트색: #333333
3. 폰트 설정
   - 제목: 굵음, 색상 #667eea
   - 본문: 일반, 색상 #333333
```

### 3단계: 각 슬라이드 입력
```
Slide 1: 타이틀 슬라이드
  - 텍스트만 입력 (위에 명시)
  - 배경: 메뉴→슬라이드→슬라이드 변경→색상→#667eea

Slides 2-15: 콘텐츠 슬라이드
  - 위 명시 내용 복사-붙여넣기
  - 코드는 코드 블록 스타일 적용
  - 이모지 포함
```

### 4단계: 페이지 번호 추가
```
메뉴: 삽입 → 슬라이드 번호
- 위치: 오른쪽 하단
- 첫 슬라이드 제외
```

### 5단계: 최종 검토
```
- 모든 슬라이드 텍스트 확인
- 색상 일관성 확인
- 폰트 크기 조정
- 이모지 표시 확인
```

### 6단계: 다운로드
```
파일 → 다운로드 → PowerPoint (.pptx)
저장: output/ppt/Chapter1_Git_시작하기.pptx
```
