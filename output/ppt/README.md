# 강의 PPT (PowerPoint)

## 📊 Git 입문 교재 - 강의 슬라이드

본 파일은 Git 입문 교재를 강의할 때 사용하는 PowerPoint 프레젠테이션입니다.

---

## 📑 구성

### 슬라이드 배분

| 장 | 주제 | 슬라이드 수 | 내용 |
|----|------|----------|------|
| 1 | Git 시작하기 | 25 | 개념 + 설치 + 첫 저장소 |
| 2 | 기본 작업 | 20 | add, commit, push, pull |
| 3 | 협업하기 | 30 | 브랜치, 병합, PR |
| 4 | 문제 해결 | 25 | revert, reset, stash, rebase |
| 5 | 실전 상황 | 20 | 5가지 문제 해결 |
| - | 부록 | 10 | 참고, FAQ |

### 슬라이드 유형

1. **타이틀 슬라이드**: 장 제목
2. **개념 슬라이드**: 설명 + 다이어그램
3. **코드 슬라이드**: 터미널 명령어
4. **실습 슬라이드**: 따라하기
5. **정리 슬라이드**: 핵심 포인트

## 📝 각 슬라이드 요소

### 제목 슬라이드
- 큰 제목 (44pt)
- 부제목 (28pt)
- 배경색 (장의 색상)

### 내용 슬라이드
- 제목 (32pt)
- 본문 (18pt)
- 이미지 (SVG 다이어그램)
- 스피커 노트

### 코드 예제
- 터미널 폰트 (Courier New)
- 검은 배경 (또는 밝은 회색)
- 흰색 텍스트

---

## 🎯 사용 방법

### 강사용
1. PowerPoint 또는 Google Slides에서 열기
2. 슬라이드 노드 보기 (F5 키)
3. 각 슬라이드별 스피커 노트 확인
4. 실시간으로 터미널 창 띄우기 (라이브 코딩)

### 학생용
1. PDF로 내보내기
2. 강의 후 슬라이드 공유
3. 복습 시 참고

---

## 🔄 생성 방법

### 자동 생성 (권장)
```bash
# Python 스크립트로 PPT 생성
python generate_ppt.py
```

### 수동 생성
1. Google Slides에서 새 프레젠테이션 생성
2. chapters/index.html 내용 참고하며 슬라이드 작성
3. SVG 다이어그램 삽입
4. 색상 일관성 유지
5. .pptx로 다운로드
