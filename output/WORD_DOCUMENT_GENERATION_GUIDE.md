#### 페이지 3: 1.1 Git이란 무엇인가?

```
[헤더: 1장 Git 시작하기]
[하이라이트 박스]

# 1.1 Git이란 무엇인가?

본문 텍스트:
Git은 버전 관리 시스템(Version Control System)입니다.
쉽게 말해, 파일의 변경 이력을 기록하고 관리해주는 도구입니다.

[사이드바: 버전 관리란?]
Word 파일을 "보고서_v1.docx", "보고서_v2.docx",
"보고서_최종.docx" 이렇게 여러 개 저장해본 경험이 있나요?
Git은 이런 방식 대신 파일의 모든 변경 기록을 효율적으로
관리해줍니다!

## Git을 사용하면 어떤 장점이 있을까?

• 변경 기록 관리: 누가, 언제, 무엇을 바꿨는지 모두 기록
• 이전 버전 복구: 실수로 삭제했거나 망친 코드를 언제든 복구 가능
• 협업 용이: 여러 사람이 같은 프로젝트에서 효율적으로 작업
• 브랜치 기능: 병렬로 여러 작업을 동시에 진행 가능

## Git의 구조

| 요소 | 설명 |
|------|------|
| 로컬 저장소 | 내 컴퓨터에 있는 파일과 변경 기록 |
| 원격 저장소 | 인터넷 서버(GitHub 등)에 있는 파일과 변경 기록 |
| 커밋 | 파일의 변경 사항을 저장하는 행위 |
```

# 1.2 Git 설치하기

## macOS에서 설치

┌─────────────────────────────────┐

Ubuntu/Debian:
┌─────────────────────────────────┐

#### 페이지 12: 1.3 사용자 정보 설정

```
# 1.3 사용자 정보 설정

Git을 사용하기 전에 가장 먼저 해야 할 일은
"나는 누구인가"를 알려주는 것입니다.
이 정보는 커밋할 때마다 기록됩니다.

## 따라하기

### Step 1: 사용자 이름 설정

┌─────────────────────────────────────────────┐
│ $ git config --global user.name "이름"      │
└─────────────────────────────────────────────┘

예:
┌─────────────────────────────────────────────┐
│ $ git config --global user.name "Kim Min-ho"│
└─────────────────────────────────────────────┘

### Step 2: 이메일 설정

┌─────────────────────────────────────────────┐
│ $ git config --global user.email "이메일"   │
└─────────────────────────────────────────────┘

예:
┌─────────────────────────────────────────────┐
│ $ git config --global user.email "kim@..."  │
└─────────────────────────────────────────────┘

## 설정 확인하기

┌─────────────────────────────────────────────┐
│ $ git config --list                         │
│ user.name=Kim Min-ho                        │
│ user.email=kim@example.com                  │
│ ...                                         │
└─────────────────────────────────────────────┘

또는 개별로 확인:

┌─────────────────────────────────────────────┐
│ $ git config user.name                      │
│ Kim Min-ho                                  │
└─────────────────────────────────────────────┘

[팁: 💡 전역 vs 로컬 설정]
--global 옵션은 컴퓨터 전체에 적용됩니다.
특정 프로젝트마다 다른 정보를 사용하려면
--global을 빼세요.
```

#### 페이지 15: 1.4 첫 번째 저장소 만들기

```
# 1.4 첫 번째 저장소 만들기

저장소(Repository)는 Git이 파일의 변경 이력을
기록하는 폴더입니다.
이제 실제로 Git 저장소를 만들어봅시다!

## 따라하기

### Step 1: 폴더 생성

터미널/명령프롬프트에서:

┌─────────────────────────────────────────────┐
│ $ mkdir my-first-project                    │
└─────────────────────────────────────────────┘

이 명령어는 "my-first-project"이라는
새로운 폴더를 만듭니다.

### Step 2: 폴더로 이동

┌─────────────────────────────────────────────┐
│ $ cd my-first-project                       │
└─────────────────────────────────────────────┘

### Step 3: Git 저장소 초기화

┌─────────────────────────────────────────────┐
│ $ git init                                  │
│ Initialized empty Git repository in ...     │
└─────────────────────────────────────────────┘

이 명령어는 폴더를 Git 저장소로 만듭니다.
".git"이라는 숨김 폴더가 생성됩니다.

## 확인해보기

저장소가 제대로 만들어졌는지 확인:

┌─────────────────────────────────────────────┐
│ $ git status                                │
│ On branch master                            │
│ No commits yet                              │
│ nothing to commit                           │
└─────────────────────────────────────────────┘

다음과 같은 메시지가 나타나면 성공입니다!

## 축하합니다! 🎉

✅ 축하합니다! 첫 번째 Git 저장소를 만들었습니다!

## 다음 단계

이제 파일을 추가하고 변경사항을 기록해보세요!
2장에서 기본 명령어들을 배워봅시다.
```
