객관식 ⭐⭐
Q1. git revert의 역할은?
A. 파일 삭제
B. 이전 커밋을 새로운 커밋으로 되돌리기
C. 브랜치 생성
D. 저장소 삭제
정답: B
단답형 ⭐⭐
Q2. 특정 커밋을 되돌리는 안전한 명령어는?
정답: git revert <커밋해시>
객관식 ⭐⭐⭐
Q3. git reset의 역할은?
A. 파일 복사
B. HEAD를 특정 커밋으로 이동
C. 브랜치 생성
D. 파일 이동
정답: B
서술형 ⭐⭐⭐
Q4. git reset과 git revert의 차이를 설명하세요.
💡 힌트: history 변경 여부
실습 ⭐⭐

□ 파일 수정

단답형 ⭐⭐
Q6. 변경사항을 임시 저장하는 명령어는?
정답: git stash
객관식 ⭐⭐
Q7. git stash의 역할은?
A. 파일 생성
B. 현재 변경사항을 임시로 저장
C. 파일 삭제
D. 커밋
정답: B
단답형 ⭐⭐
