✏️ 3장 워크북

다음 문제들을 풀고 자신의 이해도를 점검하세요.

객관식 ⭐
Q1. 브랜치의 역할은?
A. 파일 삭제
B. 독립적인 작업 공간 생성
C. 코드 압축
D. 파일 이동
정답: B
단답형 ⭐
Q2. 새로운 브랜치를 생성하는 명령어는?
정답: git branch <브랜치명>
실습 ⭐
Q3. 브랜치 생성 및 전환하기
실습 단계:
□ git branch feature
□ git checkout feature
□ 파일 수정
□ git status로 확인
객관식 ⭐⭐
Q4. git merge의 역할은?
A. 브랜치 생성
B. 다른 브랜치의 변경사항을 현재 브랜치에 병합
C. 파일 복사
D. 저장소 삭제
정답: B
서술형 ⭐⭐⭐
Q5. merge conflict가 발생했을 때 해결하는 방법을 설명하세요.
💡 힌트: 파일을 열어서 충돌 부분을 수정
단답형 ⭐
Q6. 현재 브랜치를 확인하는 명령어는?
정답: git branch
객관식 ⭐⭐
Q7. Pull Request(PR)의 역할은?
A. 파일 생성
B. 코드 리뷰 및 병합 요청
C. 브랜치 삭제
D. 저장소 생성
정답: B
실습 ⭐⭐
Q8. 브랜치 병합하기
실습 단계:
□ git checkout main
□ git merge feature
□ git log로 확인
□ git branch -d feature로 브랜치 삭제
단답형 ⭐
Q9. 특정 브랜치로 전환하는 명령어는?
정답: git checkout <브랜치명>
서술형 ⭐⭐⭐
Q10. 협업 시 브랜치 전략의 중요성을 설명하세요.
