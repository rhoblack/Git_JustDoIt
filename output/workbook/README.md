## 🎯 문제 유형

### 1. 개념 이해 (객관식)
```
Q: git add의 역할은?
① 파일을 저장소에 저장
② 변경사항을 스테이징 영역에 추가 ✓
③ 파일을 원격 저장소에 업로드
④ 브랜치를 생성
```

### 2. 명령어 입력 (단답형)
```
Q: 현재 저장소의 상태를 확인하는 명령어를 쓰세요.
A: git status
```

### 3. 상황 대처 (서술형)
```
Q: 실수로 파일을 add했을 때 취소하는 방법을 설명하세요.
A: git reset HEAD <파일명> 으로 스테이징 영역에서 제거
```

### 4. 실습 (체크리스트)
```
실습: 첫 저장소 만들기
□ 새 폴더 생성 (mkdir git-test)
□ 폴더로 이동 (cd git-test)
□ 저장소 초기화 (git init)
□ git status로 확인
```
