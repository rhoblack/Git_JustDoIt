✏️ 2장 워크북

다음 문제들을 풀고 자신의 이해도를 점검하세요.

객관식 ⭐
Q1. git add의 역할은?
A. 파일을 저장소에 저장
B. 변경사항을 스테이징 영역에 추가
C. 파일을 원격 저장소에 업로드
D. 브랜치를 생성
정답: B
단답형 ⭐
Q2. 모든 변경사항을 스테이징 영역에 추가하는 명령어는?
정답: git add .
객관식 ⭐
Q3. git commit의 역할은?
A. 파일 생성
B. 스테이징 된 변경사항을 저장소에 저장
C. 파일 삭제
D. 브랜치 생성
정답: B
실습 ⭐
Q4. 파일 수정 및 커밋하기
실습 단계:
□ README.md 파일 생성
□ git add README.md
□ git commit -m '초기 커밋'
□ git log로 확인
단답형 ⭐⭐
Q5. 원격 저장소로 코드를 업로드하는 명령어는?
정답: git push
객관식 ⭐
Q6. git pull의 역할은?
A. 파일을 삭제
B. 원격 저장소의 최신 코드를 가져오기
C. 커밋 생성
D. 브랜치 생성
정답: B
서술형 ⭐⭐
Q7. add, commit, push의 순서와 각각의 역할을 설명하세요.
💡 힌트: 스테이징 → 저장 → 업로드
단답형 ⭐
Q8. 커밋 메시지를 남기면서 커밋하는 명령어는?
정답: git commit -m '메시지'
객관식 ⭐
Q9. git log의 역할은?
A. 파일 생성
B. 커밋 이력 확인
C. 파일 수정
D. 저장소 삭제
정답: B
실습 ⭐⭐
Q10. 원격 저장소와 연결하기
실습 단계:
□ GitHub에 저장소 생성
□ git remote add origin
□ git push -u origin main
□ git status로 확인
