# Word 교재 (DOCX)

## 📘 출판용 교재

본 파일은 Git 입문 교재를 Microsoft Word 형식으로 통합한 출판 버전입니다.

│   ├── 2.3 서버에 업로드

├── 3장: 협업하기
│   ├── 3.1 브랜치 개념

## 🎨 스타일 가이드

### 제목 스타일

| 레벨 | 폰트 | 크기 | 색상 |
|------|------|------|------|
| H1 | Segoe UI | 28pt | #333 |
| H2 | Segoe UI | 24pt | 장별 색상 |
| H3 | Segoe UI | 18pt | #555 |

### 본문 스타일

- **폰트**: Segoe UI 또는 나눔고딕
- **크기**: 11pt
- **줄간격**: 1.5
- **여백**: 상하 6pt

### 코드 블록

```
폰트: Courier New
크기: 10pt
배경: #f5f5f5
테두리: 1px 회색
여백: 8pt
```

## 📊 페이지 설정

### 용지
- **크기**: A4
- **방향**: 세로
- **여백**: 상 2.5cm, 좌 2.5cm, 우 2cm, 하 2.5cm

### 헤더/푸터
- **헤더**: Git 입문 교재 | [장 제목]
- **푸터**: 페이지 번호 (중앙)

### 페이지 나누기
- 각 장마다 페이지 나누기
- 장 시작은 홀수 페이지

## 🔄 생성 방법

### 자동 생성 (권장)
```bash
# Python 스크립트로 DOCX 생성
python generate_docx.py
```

### 수동 생성
1. Microsoft Word 또는 LibreOffice Writer 열기
2. 새 문서 생성
3. 각 chapter HTML 파일의 내용 복사
4. 스타일 적용 (Heading 1, 2, 3 등)
5. SVG 이미지 삽입
6. 목차 자동 생성
7. 페이지 설정 조정
8. .docx로 저장
