## 📖 프로젝트 소개

이 교재는 **Git을 처음 배우는 개발자**를 위해 만들어졌습니다.

- ✅ **기초부터 심화까지**: Git의 기본부터 협업, 복잡한 상황 해결까지
- ✅ **따라하면서 배우기**: 각 섹션마다 구체적인 명령어와 예제 제공
- ✅ **초보자 친화적**: 전문용어를 한글로 설명하고, 실제 상황 중심의 예제
- ✅ **HTML 형식**: 웹브라우저에서 바로 확인 가능, 응답형 디자인

## 🎯 대상 독자

- Git을 처음 배우는 개발자
- CLI 명령어가 낯선 비프로그래머
- Windows, Mac, Linux 모든 환경의 사용자
- 팀 프로젝트에 참여할 예정인 신입

## 📚 교재 구조

### 1️⃣ 시작하기 (기초)
Git의 개념, 설치, 초기 설정, 첫 저장소 만들기
- Git이란 무엇인가?
- 모든 OS에서의 설치 방법
- 사용자 정보 설정
- 첫 저장소 생성

**학습 시간**: 30분 | **난이도**: ⭐

### 2️⃣ 기본 작업 (일상)
매일 사용하는 Git 명령어들
- `git add` - 파일 추가하기
- `git commit` - 변경사항 저장하기
- `git status`, `git log` - 상태 확인
- `git push`, `git pull` - 원격 저장소 동기화

**학습 시간**: 1시간 | **난이도**: ⭐⭐

### 3️⃣ 협업하기 (중급)
팀과 함께 효율적으로 작업하는 방법
- 브랜치의 개념과 사용법
- 브랜치 생성, 전환, 병합
- 충돌 해결하기
- Pull Request와 협업 워크플로우

**학습 시간**: 1시간 30분 | **난이도**: ⭐⭐⭐

### 4️⃣ 문제 해결 (심화)
실수를 바로잡고 깔끔한 히스토리 만들기
- `git revert` - 커밋 되돌리기 (안전)
- `git reset` - 커밋 삭제하기 (강력)
- `git stash` - 변경사항 임시 저장
- `git rebase` - 히스토리 정리
- `git cherry-pick` - 특정 커밋만 적용

**학습 시간**: 1시간 | **난이도**: ⭐⭐⭐⭐

### 5️⃣ 실전 상황 (종합)
실제 프로젝트에서 마주치는 5가지 상황과 해결책
- 실수로 커밋한 파일 제거하기
- 이전 버전으로 완전히 되돌리기
- 특정 파일만 다른 브랜치에서 가져오기
- 협업할 때 최신 코드 유지하기
- 빠른 참조 가이드 + 핵심 팁

**학습 시간**: 1시간 | **난이도**: ⭐⭐⭐⭐⭐

## 🚀 빠른 시작

### 웹브라우저에서 보기

1. 이 리포지토리를 클론하기:
```bash
git clone https://github.com/rhoblack/Git_JustDoIt.git
cd Git_JustDoIt
```

2. 브라우저에서 `index.html` 열기:
   - **Windows**: `index.html` 파일을 더블클릭
   - **Mac/Linux**: `open index.html` 또는 `xdg-open index.html`

3. 각 장을 순서대로 읽으면서 직접 터미널에서 명령어 실행하기

### 추천 학습 방법

```
1️⃣ 교재의 "따라하기" 섹션 읽기
           ↓
2️⃣ 터미널을 열고 명령어 직접 입력
           ↓
3️⃣ "팁"과 "하이라이트" 박스 확인
           ↓
4️⃣ 다음 장으로 진행
```

## ❓ 자주 묻는 질문 (FAQ)

**Q: 터미널을 사용해본 적이 없어도 될까요?**
A: 네! 이 교재는 터미널 초보자를 기준으로 작성되었습니다. 각 명령어를 정확하게 설명하고 예제를 제공합니다.

**Q: GUI 도구(GitHub Desktop, SourceTree)와는 다른가요?**
A: 네, 이 교재는 CLI(명령어)를 중심으로 합니다. GUI도구를 사용해도 기본 개념은 같습니다.

**Q: 얼마나 오래 걸릴까요?**
A: 전체 교재를 한 번 읽으면서 실습하면 **4~6시간** 정도 걸립니다.

**Q: 코드를 쓸 줄 모르는데도 배울 수 있나요?**
A: 물론입니다! Git은 코드를 관리하는 도구일 뿐, 언어 지식이 필수는 아닙니다.
