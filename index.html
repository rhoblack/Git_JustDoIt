📚 Git 입문 교재

초보자부터 협업 전문가까지 - 완전한 가이드

이 교재는 어떻게 구성되어 있나요?

Git의 기초부터 협업, 그리고 복잡한 상황까지 단계별로 배워볼 수 있습니다.
각 장에서 "따라하기" 예제를 통해 직접 경험하며 학습하세요!

1️⃣ 시작하기

기초 (초보자 필수)

Git을 처음 사용하시나요? 여기서 시작하세요!

  • Git이란 무엇인가?
  • 설치 방법 (모든 환경)
  • 사용자 정보 설정
  • 첫 저장소 만들기
🟢 입문 학습 시작

2️⃣ 기본 작업

일상 사용 (반드시 알아야 함)

매일 사용하는 기본 명령어들을 배워봅시다.

  • 파일 추가하기 (add)
  • 변경사항 저장하기 (commit)
  • 상태 확인하기
  • Push & Pull
🔵 초급 학습 시작

3️⃣ 협업하기

팀 작업 (중급)

팀원들과 함께 효율적으로 협업하는 방법을 배워봅시다.

  • 브랜치 이해하기
  • 브랜치 만들고 전환하기
  • 브랜치 병합하기 (merge)
  • 충돌 해결하기
🟠 중급 학습 시작

4️⃣ 문제 해결

심화 (고급 기술)

실수를 바로잡고 더 깔끔한 히스토리를 만드는 방법입니다.

  • 커밋 되돌리기
  • 변경사항 임시 저장
  • 히스토리 정리하기
  • 특정 커밋 선택 적용
🔴 고급 학습 시작

5️⃣ 실전 상황

현실의 문제들 (종합)

실제로 마주치는 상황들과 그 해결 방법들입니다.

  • 실수로 커밋한 파일 제거
  • 이전 버전으로 되돌리기
  • 변경사항 일부만 가져오기
  • 최신 코드 유지하기
🟣 종합 학습 시작

💡 팁: 각 장을 순서대로 따라가며 직접 명령어를 입력해보세요!
