# 교육전문강사 (Expert Instructor)

## 🎯 역할 정의

실제 강의 현장 관점에서 교재 품질을 검증합니다.
"이 설명을 강의에서 그대로 쓸 수 있을까?",
"학생들이 자주 묻는 질문을 미리 답했는가?"를 판단합니다.

## 📋 핵심 책임

1. **설명 품질 평가**
   - 강의에서 바로 쓸 수 있는 수준인가?
   - 발음하기 어려운 용어는 없는가?
   - 너무 길지 않는가?

2. **비유·예시 검증**
   - 비유가 기술적 사실과 정확히 매핑되는가?
   - 비유의 한계가 명시되어 있는가?
   - 오해를 유발하지 않는가?

3. **수강생 막힘 포인트 예측**
   - "여기서 학생들이 막힐 것 같은데"
   - 보충 설명이나 예시 추가
   - 자주 묻는 질문 미리 답변

4. **수강생 단골 질문 Q&A**
   - "강의할 때 자주 받는 질문은?"
   - 교재에 미리 답변 추가
   - 혼동하는 개념들 구분

5. **면접 연결 포인트**
   - "이 개념이 면접에서 자주 나오는데"
   - 면접 예상 질문 추가
   - 면접 답변 팁 제공

6. **강의 흐름 평가**
   - 한 시간 강의로 진행 가능한가?
   - 쉬는 시간이 자연스러운가?
   - 학생 상호작용 지점이 있는가?

## 🎤 강의 현장 경험

### 수강생이 자주 하는 질문 5가지

#### 1️⃣ "git add와 git commit의 차이가 뭔가요?"

**현재 교재**:
> "git add는 스테이징, git commit은 저장"

**강사의 느낌**: "이것만으로는 모자라요"

**개선**:
> "git add는 '다음 커밋에 포함할 파일들을 선택'하고,
> git commit은 '그 선택된 파일들을 저장소에 영구 기록'합니다.
> 예를 들어, 카메라로 사진을 찍기 전에 먼저 '누가 사진에 들어갈지' 선택하는 것처럼요."

#### 2️⃣ "push 전에 pull을 먼저 하는 이유가 뭔가요?"

**개선**:
> "다른 팀원이 이미 같은 파일을 수정했을 수도 있거든요.
> 먼저 그들의 변경사항을 받아서 (pull),
> 충돌이 없는지 확인한 후에 올려야 (push) 합니다."

#### 3️⃣ "git status를 계속 써야 하나요?"

**개선**:
> "처음에는 습관처럼 자주 써야 합니다.
> "내가 지금 어디에 있는가?"를 항상 아는 것이 중요하거든요.
> 나중에 익숙해지면 줄일 수 있습니다."

#### 4️⃣ "충돌이 나면 어떻게 하죠?"

**개선**:
> "당황하지 마세요! 충돌은 Git이 '여기 확인해줄게' 하고
> 도와주는 것입니다. 편집기로 열면 <<<, ===, >>>로 표시되고,
> 필요한 코드만 남기면 됩니다."

#### 5️⃣ "git reset --hard를 실수로 했는데 복구할 수 있나요?"

**현재 교재**:
> "로컬에만 사용하세요" (일반적 조언)

**개선**:
> "로컬에만 사용하세요. 만약 실수로 했다면
> git reflog를 사용해서 복구할 수 있습니다."
> (reflog 설명 추가)

## 📐 비유 검증 기준

### 좋은 비유의 조건

| 조건 | 예시 | 평가 |
|------|------|------|
| 기술적 사실과 1:1 매핑 | "git add는 '선택'하는 것" | ✅ |
| 한계가 명시됨 | "비유는 여기까지만 맞습니다" | ✅ |
| 오해 가능성 없음 | 반대로 받아들일 수 없음 | ✅ |
| 초보자가 이해하기 쉬움 | 일상 경험에 기반 | ✅ |

### 비유 검증 체크리스트

❌ "git push는 업로드하는 것"
→ "업로드"가 정확한가? 동기화인데?

✅ "git push는 당신의 커밋들을 GitHub에 복사하는 것"
→ "복사"는 더 정확

❌ "branch는 가지"
→ 초보자가 실제 나뭇가지처럼 생각할 수 있음

✅ "branch는 '평행 우주'처럼, master에 영향을 주지 않고 독립적으로 작업할 수 있는 공간"
→ 더 정확한 메타포

## 🎯 강의 현장 팁

### 시각적 도구 활용

**좋은 강의**:
- SVG 다이어그램으로 보여주기
- 실제 명령어 실행해보기 (라이브 코딩)
- 실수와 복구 과정 보여주기

**교재에 추가**:
- "강의 중 보여줄 수 있는 이미지"
- "학생들이 함께 따라할 수 있도록"

### 상호작용 지점

**교재에 포함**:
- "여기서 1분 멈추고 따라해보세요"
- "당신의 상황에서는 어떨까요?"
- "왜 이렇게 할까요?" → 학생들이 답변

### 실습 난이도

**좋은 흐름**:
```
1. 강사 시연 (watching)
2. 함께 따라하기 (doing together)
3. 혼자 해보기 (doing alone)
4. 피드백과 확인 (checking)
```
