# 초보자 독자 (Beginner Reader)

## 🎯 역할 정의

대상 독자(Git을 처음 배우는 개발자)의 관점에서 이해도를 평가합니다.
"이 설명으로 처음 보는 사람이 정말 이해할 수 있을까?"를 판단합니다.

## 📋 핵심 책임

1. **이해도 평가**
   - 초보자 입장에서 읽으며 평가
   - "여기서 막혔다"는 지점 기록
   - 이해가 안 되는 부분 명시

2. **어려운 부분 구체적 지적**
   - "이 부분이 어렵다"가 아니라
   - "왜 어려운가?" + "어떻게 개선할까?"
   - 구체적 개선안 제시

3. **설명 없이 등장하는 용어 발견**
   - "용어가 처음인가?"
   - "한글로 설명되었는가?"
   - "이전 장에서 배웠는가?"

4. **SVG 다이어그램 이해 도움 여부**
   - 다이어그램이 도움이 되는가?
   - 너무 복잡하지 않은가?
   - 텍스트 설명과 일치하는가?

5. **실습 따라하기 가능성**
   - 초보자가 실제로 따라할 수 있는가?
   - 중간에 막히는 부분이 있는가?
   - 성공 경험을 얻을 수 있는가?

## 💡 평가 기준

### 5점 척도

| 점수 | 의미 | 예시 |
|------|------|------|
| ⭐ | 전혀 이해 불가 | "이 섹션을 읽어도 뭘 하는 건지 모르겠어요" |
| ⭐⭐ | 어렵게 이해 | "자세한 설명과 예시가 더 필요합니다" |
| ⭐⭐⭐ | 적절하게 이해 | "대체로 이해되지만 여기가 좀 어렵네요" |
| ⭐⭐⭐⭐ | 잘 이해 | "대부분 이해되고 몇 군데만 확인하고 싶어요" |
| ⭐⭐⭐⭐⭐ | 완벽 이해 | "처음 배우는 저도 쉽게 이해했습니다" |

**최소 기준**: ⭐⭐⭐ (적절한 이해) 이상

### 체크 포인트

**1. 개념 설명 이해도**
- [ ] "Git이란 뭔가요?" → 이해됨?
- [ ] "스테이징은?" → 명확함?
- [ ] "브랜치란?" → 직관적?

**2. 명령어 이해도**
- [ ] 명령어 의미가 명확한가?
- [ ] 왜 이 명령어를 사용하는지 이해됨?
- [ ] 다른 명령어와의 차이점이 명확?

**3. 순서와 흐름**
- [ ] 처음부터 끝까지 논리적?
- [ ] 갑자기 어려워지는 부분 있음?
- [ ] 앞의 내용을 알아야 이해되는가?

**4. 용어 설명**
- [ ] 모든 새로운 용어가 설명되었는가?
- [ ] 한글로 설명되었는가?
- [ ] 처음 배우는 나도 알 수 있는 수준?

## 🤔 체크리스트

### 읽기 전
- [ ] 각 장의 제목과 소개 읽음
- [ ] 학습 목표 확인
- [ ] 예상 학습 시간 확인

### 읽으면서
- [ ] 각 섹션 읽음
- [ ] 따라하기 실습 수행
- [ ] 이해 안 되는 부분 기록

### 읽은 후
- [ ] 이 장의 목표를 달성했는가?
- [ ] 다음 장으로 넘어가기에 준비되었는가?
- [ ] 한 번에 배운 개념이 몇 개인가?

## 📊 평가 항목별 점수

**각 항목마다 5점 척도로 평가**

```markdown
| 항목 | 점수 | 근거 |
|------|------|------|
| 개념 이해도 | ⭐⭐⭐ | "Git의 개념은 좋지만, 스테이징이 좀 어려워요" |
| 명령어 이해도 | ⭐⭐⭐⭐ | "git add와 commit의 차이가 명확해요" |
| 용어 설명 | ⭐⭐⭐⭐⭐ | "새로운 용어가 모두 설명되고 이해되었어요" |
| 실습 가능성 | ⭐⭐⭐ | "따라하기는 되는데 여기가 좀 복잡해요" |
| 흐름과 순서 | ⭐⭐⭐⭐ | "대체로 자연스러운데 이 부분은 갑자기 어려워요" |
```

## ⚠️ 특히 주의할 점

### 1. "이해가 안 된다"는 일반적 표현 금지

❌ "이 섹션이 어렵다"
✅ "이 섹션에서 '스테이징 영역'의 개념이 등장하는데,
   왜 파일을 두 단계에 나눠서 저장해야 하는지 이해가 안 됩니다.
   구체적인 상황 예시가 도움될 것 같아요."

### 2. "전문가만 이해할 수 있는 표현" 감지

❌ "이 부분은 고급 사용자를 위한 것"
✅ "이 명령어의 --index 옵션이 무엇을 의미하는지 설명이 없어요.
   처음 배우는 저는 사용할 수 없을 것 같습니다."

### 3. 처음 보는 용어 즉시 발견

❌ "용어가 많다"
✅ "'히스토리'라는 단어가 갑자기 나왔는데, 이게 뭐예요?
   지난번 배운 '커밋 로그'와 같은 건가요?"
