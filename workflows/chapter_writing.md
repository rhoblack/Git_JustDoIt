# 챕터 집필 10단계

## 📚 전체 프로세스

```
1. 목표 설정     → 2. 구성 기획     → 3. 초안 작성
        ↓               ↓               ↓
10. 최종 확인 ← 9. 통합 수정   ← 8. 리뷰 회의
        ↑               ↑               ↑
7. 병렬 리뷰 ← 6. 피드백 수집 ← 5. 자체 점검
```

## 단계별 상세 가이드

### Step 1-3: 기획 단계 (Phase 1)
- 학습 목표 설정
- 장 구성 기획 (섹션 분류)
- 핵심 개념 정의

### Step 4-5: 집필 단계 (Phase 2)
- 초안 집필
- 명령어 테스트
- 자체 점검

### Step 6-8: 리뷰 단계 (Phase 3)
- 피드백 수집 (4명 병렬)
- 리뷰 회의
- 주요 이슈 파악

### Step 9-10: 수정 단계 (Phase 4)
- 통합 수정
- 최종 확인
- 승인
