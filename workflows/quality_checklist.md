# 품질 체크리스트 (8영역)

## 📋 8가지 품질 영역

모든 章은 다음 8가지 영역에서 검증됩니다.

---

## 1️⃣ 구조 & 형식 (Structure & Format)

### 체크리스트
- [ ] HTML 문법 오류 없음
- [ ] 섹션 제목이 명확함
- [ ] 흐름이 논리적
- [ ] 과도한 섹션 분리는 없는가
- [ ] 각 섹션이 2000~4000자인가
- [ ] 네비게이션이 명확한가

### 평가 기준
| 점수 | 기준 |
|------|------|
| ⭐⭐⭐⭐⭐ | 완벽한 구조, 읽기 쉬움 |
| ⭐⭐⭐⭐ | 좋은 구조, 약간 개선 가능 |
| ⭐⭐⭐ | 적절한 구조 |
| ⭐⭐ | 개선 필요 |
| ⭐ | 전면 재작성 필요 |

### 체크리스트

- [ ] 정보가 정확함
- [ ] 중복이 없음

- [ ] 예시가 적절함
- [ ] 깊이가 적절함

| 완성도 | ⭐~⭐⭐⭐⭐ |

## 3️⃣ 코드 품질 (Code Quality)

### Git 명령어 체크리스트
- [ ] 모든 명령어가 정확함
- [ ] 문법이 올바름
- [ ] 옵션 조합이 맞음
- [ ] 모든 OS에서 동작 가능
- [ ] 버전 호환성 확인
- [ ] 위험한 명령어는 경고 표시

### 평가 기준

| 비효율적 코드 | 🟡 Major |
| 스타일 개선 가능 | 🟢 Minor |

## 5️⃣ 특수 코너 (Special Sections)

5가지 Aside 박스가 포함되어야 합니다:

| 박스 | 개수 | 예시 |
|------|------|------|
| 💡 실무 팁 | 2~3개 | "git add 할 때는 .을 사용하세요" |
| 📌 중요 정보 | 2~3개 | "첫 실습은 반드시 성공해야 합니다" |
| ⚠️ 경고 | 1~2개 | "이 명령어는 복구 불가능합니다" |
| 🎯 따라하기 | 3~5개 | "Step 1: git init을 실행하세요" |
| 📖 참조 | 1~2개 | "테이블로 명령어 정리" |

### 체크리스트
- [ ] 💡 팁이 충분함
- [ ] 📌 중요 정보가 명확함
- [ ] ⚠️ 경고가 명확함
- [ ] 🎯 따라하기가 구체적
- [ ] 📖 참조가 유용함

## 6️⃣ 실습 & 연습문제 (Exercises & Practice)

### 실습 설계 평가

**첫 실습**:
- [ ] 반드시 성공하는가? (100% success rate)
- [ ] 자신감을 주는가?
- [ ] 너무 길지 않은가?

**전체 실습**:
- [ ] 3~5개 정도인가?
- [ ] 난이도가 점진적으로 증가하는가?
- [ ] 각각 학습 목표와 연결되는가?

**연습문제** (블룸 분류):
- [ ] 기억(1): 정의 묻기
- [ ] 이해(2): 차이 설명하기
- [ ] 적용(3): 명령어 사용하기
- [ ] 분석(4): 오류 찾기
- [ ] 평가(5): 상황에 맞는 선택

### 평가 기준
| 항목 | 점수 |
|------|------|
| 첫 실습 성공도 | ⭐~⭐⭐⭐⭐ |
| 난이도 적절성 | ⭐~⭐⭐⭐⭐ |
| 블룸 분류 다양성 | ⭐~⭐⭐⭐⭐ |

## 7️⃣ 심리적 품질 (Psychological Quality)

### 동기 관리
- [ ] 왜 배우는가가 명확함
- [ ] 학습자가 포기하지 않도록 설계
- [ ] 성공 경험을 제공함
- [ ] 자신감을 높임

### 불안 관리
- [ ] 어려운 부분에 사전 안심 메시지
- [ ] 위험한 부분이 명확하게 경고됨
- [ ] "실수는 정상"이라는 메시지
- [ ] 실패 복구 방법이 제시됨

### 감정 곡선
- [ ] 도입: 호기심 ↑
- [ ] 개념: 약간 불안
- [ ] 예시: 이해 시작
- [ ] 실습: 불안 ↓
- [ ] 완료: 성취감 ↑

### 평가 기준
| 항목 | 점수 |
|------|------|
| 동기 유지 | ⭐~⭐⭐⭐⭐ |
| 불안 관리 | ⭐~⭐⭐⭐⭐ |

## 📊 최종 평가 기준

### Critical Issues (즉시 수정 필수)
- 기술적 오류 (잘못된 명령어, 개념)
- 명백한 누락
- 심각한 혼동 유발 표현
- 데이터 손상 경고 부재

### Major Issues (수정 권장)
- 불명확한 설명
- 개선 가능한 예시
- 비효율적 명령어 사용
- 시간 분배 문제

### Minor Issues (참고사항)
- 문법 개선
- 스타일 조정
- 추가 설명 가능
