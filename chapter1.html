Git을 처음 만나는 분을 위한 완벽한 시작 가이드

  • 터미널(명령 프롬프트)을 열고 기본 명령어를 입력할 수 있다
  • Git이 무엇이고 왜 필요한지 설명할 수 있다
  • 내 컴퓨터에 Git을 설치하고 확인할 수 있다
  • 첫 번째 Git 저장소를 만들고 상태를 확인할 수 있다

💡왜 Git을 배우나요?

이런 경험 있으신가요?

보고서_v1.docx
보고서_v2.docx
보고서_최종.docx
보고서_진짜최종.docx
보고서_진짜진짜최종_수정.docx

파일을 수정할 때마다 새 이름으로 저장하면, 어떤 파일이 최신인지 헷갈리고 이전 내용으로 돌아가기도 어렵습니다.

Git은 이 문제를 해결합니다. 파일 하나만 유지하면서, 모든 변경 이력을 자동으로 기록해줍니다. 마치 문서의 "실행 취소" 기능이 무한대로 확장된 것과 같습니다.

📌 Git은 전 세계 개발자의 90% 이상이 사용하는 도구입니다.
개발자뿐 아니라 디자이너, 기획자, 문서 작업자도 활용할 수 있습니다.

🖥️1.1 터미널 알아보기

📌 용어: 터미널 / 명령 프롬프트

한글 정의: 컴퓨터에게 글자로 명령을 내리는 창입니다.

일상 비유: 음성 비서(시리, 빅스비)에게 말로 명령하는 것처럼, 터미널은 컴퓨터에게 글자로 명령하는 도구입니다. "폴더 만들어줘", "파일 목록 보여줘" 같은 명령을 타이핑합니다.

왜 필요한가? Git은 터미널에서 명령어를 입력해 사용합니다. 마우스 클릭 대신 직접 명령을 치면, 더 빠르고 정확하게 작업할 수 있습니다.

운영체제별 터미널 열기

Windows에서 터미널 열기
  1. 방법 1: 키보드에서 Windows 키 + R을 누르고, cmd 입력 후 Enter
  2. 방법 2: 시작 메뉴에서 "명령 프롬프트" 또는 "PowerShell" 검색
  3. 방법 3 (추천): Git 설치 후 바탕화면에서 마우스 우클릭 → "Git Bash Here"
macOS에서 터미널 열기
  1. Command + Space를 눌러 Spotlight 열기
  2. "터미널" 또는 "Terminal" 입력 후 Enter
Linux에서 터미널 열기
  1. Ctrl + Alt + T 단축키 (대부분의 배포판)
  2. 또는 프로그램 메뉴에서 "Terminal" 검색

직접 해보기: 터미널 기본 명령어

터미널을 열었다면, 다음 명령어를 하나씩 입력해보세요. 각 명령어 입력 후 Enter를 누릅니다.

Step 1: 현재 위치 확인하기
$ pwd

📊 예상 결과:

/Users/사용자이름

이 명령어는 "Print Working Directory"의 약자로, 지금 내가 어디에 있는지 알려줍니다. Windows 명령 프롬프트에서는 cd만 입력하면 동일한 결과를 얻을 수 있습니다.

Step 2: 폴더 안의 파일 목록 보기
$ ls

📊 예상 결과:

Desktop Documents Downloads Music Pictures

현재 폴더에 있는 파일과 폴더 목록이 나타납니다. Windows 명령 프롬프트에서는 dir을 사용합니다.

Step 3: 새 폴더 만들기
$ mkdir test-folder

"test-folder"라는 폴더가 만들어집니다. mkdir은 "Make Directory"의 약자입니다.

Step 4: 폴더로 이동하기
$ cd test-folder

"test-folder" 안으로 이동합니다. cd는 "Change Directory"의 약자입니다.

✅ 성공!
터미널에서 폴더를 만들고 이동했습니다! 이제 Git을 사용할 준비가 되었습니다.
💡 터미널이 어렵게 느껴지나요?
처음에는 누구나 그렇습니다. 지금은 위의 4개 명령어(pwd, ls, mkdir, cd)만 기억하면 충분합니다. Git을 배우면서 자연스럽게 익숙해질 거예요.

📖1.2 Git이란 무엇인가?

Git은 버전 관리 시스템(Version Control System)입니다. 쉽게 말하면, 파일의 변경 이력을 자동으로 기록하고 관리해주는 도구입니다.

📌 용어: 버전 관리 시스템

한글 정의: 파일의 변경 내역을 시간순으로 기록하고, 언제든 이전 상태로 되돌릴 수 있게 해주는 시스템입니다.

일상 비유: Google Docs에서 "버전 기록"을 클릭하면, 문서의 모든 수정 이력이 보이죠? Git은 이와 같은 기능을 모든 종류의 파일에 제공합니다.

Git을 사용하면 어떤 장점이 있을까?

  • 변경 기록 관리: 누가, 언제, 무엇을 바꿨는지 모두 기록
  • 이전 버전 복구: 실수로 삭제했거나 망친 파일을 언제든 복구 가능
  • 협업 용이: 여러 사람이 같은 프로젝트에서 효율적으로 작업
  • 안전한 실험: 새로운 시도를 해보고, 마음에 안 들면 되돌리기

핵심 용어 알아보기

📌 용어: 저장소 (Repository)

한글 정의: Git이 파일의 변경 이력을 기록하는 폴더입니다.

일상 비유: 일반 폴더는 파일만 저장하는 서랍이라면, Git 저장소는 모든 파일의 변경 일지까지 함께 기록하는 "스마트 서랍"입니다.

왜 필요한가? 저장소를 만들어야 Git이 그 폴더의 변경사항을 추적하기 시작합니다.

📌 용어: 커밋 (Commit)

한글 정의: 변경사항을 저장소에 기록하는 행위입니다. "저장 버튼"과 비슷합니다.

일상 비유: Word에서 Ctrl+S로 저장하는 것과 같습니다. 다만 Git의 커밋은 "어떤 내용이 바뀌었는지" 메모도 함께 남깁니다.

왜 필요한가? 커밋이 있어야 나중에 "지난주 화요일 상태로 되돌려줘"가 가능합니다.

요소 설명 비유
로컬 저장소 내 컴퓨터에 있는 Git 저장소 내 컴퓨터의 스마트 서랍
원격 저장소 인터넷 서버(GitHub 등)에 있는 저장소 클라우드 백업 서랍
커밋 변경 사항을 기록하는 행위 Ctrl+S 저장 + 메모

💻1.3 Git 설치하기

지금부터 실제로 Git을 설치해봅시다. 아래에서 본인의 운영체제를 찾아 따라하세요.

Windows에서 설치하기

Step 1: 설치 파일 다운로드
  1. 웹 브라우저에서 git-scm.com에 접속합니다
  2. "Download for Windows" 버튼을 클릭합니다
  3. 다운로드된 설치 파일(.exe)을 실행합니다
Step 2: 설치 진행
  1. 설치 창이 열리면, 모든 항목을 기본값으로 두고 "Next"를 클릭합니다
  2. 마지막에 "Install"을 클릭하면 설치가 완료됩니다

설치가 완료되면 "Git Bash"라는 프로그램이 함께 설치됩니다. 이것이 Windows에서 Git을 사용하는 터미널입니다.

macOS에서 설치하기

터미널에서 한 줄 입력:
$ brew install git

Homebrew가 없다면, 터미널에서 xcode-select --install을 입력하면 Git이 함께 설치됩니다.

Linux에서 설치하기

Ubuntu/Debian:
$ sudo apt-get install git
Fedora:
$ sudo yum install git

직접 해보기: 설치 확인

Step 1: 설치 확인 명령어 입력
$ git --version

📊 예상 결과:

git version 2.43.0

(버전 숫자는 다를 수 있습니다. 숫자가 나오면 성공입니다!)

✅ 성공!
Git이 내 컴퓨터에 설치되었습니다!

⚙️1.4 사용자 정보 설정하기

Git을 사용하기 전에 "나는 누구인가"를 알려줘야 합니다. 이 정보는 변경사항을 기록(커밋)할 때마다 자동으로 기록됩니다.

📌 왜 설정해야 하나요?
팀 프로젝트에서 누가 어떤 변경을 했는지 알아야 하기 때문입니다. "김민호가 로그인 기능을 추가했다"처럼 기록됩니다.

직접 해보기

Step 1: 사용자 이름 설정
$ git config --global user.name "당신의이름"

예시:

$ git config --global user.name "Kim Min-ho"
Step 2: 이메일 설정
$ git config --global user.email "당신의이메일@example.com"

예시:

$ git config --global user.email "kim@gmail.com"
Step 3: 설정 확인하기
$ git config user.name

📊 예상 결과:

Kim Min-ho
$ git config user.email

📊 예상 결과:

kim@gmail.com
✅ 성공!
Git에 내 이름과 이메일을 등록했습니다!
💡 전역 vs 로컬 설정
--global 옵션은 컴퓨터 전체에 적용됩니다. 특정 프로젝트마다 다른 이름/이메일을 사용하려면 해당 프로젝트 폴더에서 --global을 빼고 입력하면 됩니다.

🎯1.5 첫 번째 Git 저장소 만들기

이제 실제로 Git 저장소를 만들어봅시다! 이것이 오늘의 하이라이트입니다.

📌 용어: git init

한글 정의: 일반 폴더를 Git 저장소로 만드는 명령어입니다. "initialize(초기화)"의 줄임말입니다.

일상 비유: 새 노트를 꺼내서 첫 페이지에 "변경 일지"라고 쓰는 것과 같습니다. 이제부터 이 폴더에서 일어나는 모든 변경을 기록할 준비가 됩니다.

직접 해보기

Step 1: 프로젝트 폴더 만들기
$ mkdir my-first-project

"my-first-project"이라는 새 폴더가 만들어집니다.

Step 2: 폴더로 이동하기
$ cd my-first-project
Step 3: Git 저장소 만들기
$ git init

📊 예상 결과:

Initialized empty Git repository in /Users/.../my-first-project/.git/

이 메시지가 나오면 성공입니다! 폴더 안에 .git이라는 숨김 폴더가 생겼습니다. 이 폴더가 모든 변경 기록을 보관합니다.

Step 4: 상태 확인하기
$ git status

📊 예상 결과:

On branch master

No commits yet

nothing to commit

이 메시지는 "Git 저장소가 준비되었지만, 아직 아무것도 저장하지 않았다"는 뜻입니다.

Step 5: 첫 번째 파일 만들고 저장해보기
$ echo "Hello, Git!" > hello.txt

"Hello, Git!"이라는 내용이 담긴 hello.txt 파일이 만들어집니다.

$ git status

📊 예상 결과:

Untracked files:
hello.txt

"Untracked"는 "Git이 아직 추적하지 않는 파일"이라는 뜻입니다. 다음 장에서 이 파일을 Git에 등록하는 방법을 배웁니다!

✅ 축하합니다!
첫 번째 Git 저장소를 만들고, 파일까지 생성했습니다!
이것이 Git 작업의 시작점입니다.
